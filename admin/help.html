FAQ

Frequently Asked Questions

How do I create a new quiz?

Open the Quizzes section and select the create quiz option. Enter the quiz details, configure timing and marks, add questions, then publish the quiz when it is ready.

Can teachers create their own quizzes?

Yes. Teachers can create quizzes, manage questions, configure quiz settings, publish quizzes, and review student performance according to their permissions.

Can I edit a published quiz?

Quiz editing depends on the current quiz status and whether students have already started attempting it. Review the quiz settings before making changes to an active assessment.

How are quiz results calculated?

Results are calculated automatically using the marks assigned to questions, correct answers, unanswered questions, and any configured negative marking.

How can I export results?

Open the Results or Reports section and use the available export controls. Filters can be applied before exporting the required dataset.

What happens if a student runs out of time?

A timed quiz can automatically submit the student's current answers when the configured duration expires.

Can an administrator deactivate a user?

Yes. Administrators can manage user account status from the Students and Teachers sections.
